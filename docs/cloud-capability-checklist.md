# 云能力核验清单

供维护者新增或调整 provider、资源类型、操作及成本口径时使用。每次核验一个具体能力，例如“列出 D1 数据库”或“查询 AWS 本月 credits 抵扣”，不要仅以云厂商为单位勾选“支持”。普通用户查看 [支持矩阵](../README.md#支持哪些云)。

## 1. 能力与适用范围

- [ ] 说明云产品、资源类型和实际行为，区分清单查询、详情查询与写操作。
- [ ] 明确账号、项目、订阅、隔间、区域或分区的边界，以及是否递归子范围。
- [ ] 记录产品限制和不支持的操作；同一产品名或同一看板栏目不代表各云能力等价。
- [ ] 对照 `capabilities` 和 CLI/MCP 的实际入口，不把云端存在的 API 直接写成 noc 已支持。

## 2. 官方依据与版本

- [ ] 给出直接支持结论的官方 API、CLI 或定价文档链接，记录核对日期和 API/CLI 版本。
- [ ] 搜索结果仅用于定位资料；阅读原文，核对域名、产品和版本是否适用。
- [ ] 用户指定的链接同样检查适用性；机器可读 API 模型能证明接口结构，不能单独证明权限、费用或业务效果。
- [ ] 分别说明官方文档确认的事实、当前实现和实际验证结果；未验证的范围写明“未验证”，不按来源数量打分。

## 3. 身份、权限与费用

- [ ] 明确身份来源：CLI profile、默认账号、环境变量或系统凭据存储；不把凭据值写入配置或日志。
- [ ] 列出目标操作和账号发现分别需要的权限；身份验证通过不等于具备所有资源权限。
- [ ] 核对每个实际调用的接口是否计费，包括分页、详情补查、重试及查询数据量；不承诺整个命令一概免费。
- [ ] 对成本数据说明时间范围、时区、账期/自然月、币种、抵扣项、订阅费及税费等包含或排除项。
- [ ] 对可能计费的查询说明触发方式、缓存与查询上限；测试不得自动开启服务或扩大权限。

## 4. 请求与结果处理

- [ ] 检查分页、嵌套响应、空结果、限流、超时和非零退出码；不能把第一页当成全量结果。
- [ ] 校验 ID、名称、区域、状态、金额与容量单位；同名或重复 ID 需要按账号/区域等收窄。
- [ ] 区分成功空查询、列表失败、部分详情失败与未配置，不用零值代替未知值。
- [ ] 列表失败保留对应范围旧数据；部分采集标记 `partial`；只有成功的空查询才清空范围。
- [ ] 核对 `collection_status` 和 `last_success_at` 的范围，避免把全局生成时间当作各资源采集时间。

## 5. 写操作与验证

- [ ] 若只支持查询，确认没有隐含写操作，并明确拒绝不支持的操作。
- [ ] 若支持写操作，核对目标解析、预览、确认要求、审计和执行后验证；重启的优雅/硬重置差异须说明。
- [ ] 离线预览不读取凭据、不调用云 API；失败或结果未知时，先检查实际状态，不盲目重试写操作。
- [ ] 用匿名化夹具验证关键结果和失败路径，测试不得读取真实工作区或依赖在线账号。
- [ ] 如进行在线验证，记录实际覆盖范围、日期和脱敏结果；仅在任务已授权的范围内执行，未实测不能称为“实测通过”。

## 6. 对外说明与安装结果

- [ ] provider、同步逻辑、看板列和 `capabilities` 对同一能力的描述一致。
- [ ] README 支持矩阵、完整版模板及公开引导版保持一致，限制放在对应能力说明中。
- [ ] 用户能找到必要依赖、一个可执行示例、常见失败原因和反馈入口。
- [ ] 按仓库约定测试、重装工具并运行 `ops setup`，确认本机生成版包含修改且保留已有扩展。
- [ ] 对发布包本身检查文件、版本和依赖，不将源码提交、安装成功与远端发布成功混为一谈。

## 核验摘要模板

可用于 PR 中的行为与验证说明，仅填写与本次能力有关的项目。未适用项说明原因，未确认项保持“未验证”。公开摘要不包含账号、资源 ID、内部地址、个人路径、凭据或原始响应；遵守 [公开内容要求](../PUBLIC_CONTENT.md)。

| 项目 | 填写内容 |
|---|---|
| 能力 | 云产品、资源类型、查询或写操作 |
| 范围与限制 | 账号/区域等边界，支持和不支持的行为 |
| 官方依据 | 官方链接、核对日期、API/CLI 版本 |
| 权限与费用 | 身份来源、最小权限、计费接口及触发方式 |
| 数据口径 | 分页、字段单位、时间范围、未知值处理 |
| 失败与写入处理 | 缓存保留、部分结果、确认/审计/状态验证 |
| 验证证据 | 实现位置、测试命令与结果；在线验证是否执行及覆盖范围 |
| 用户说明 | 支持矩阵、skill 和生成版的对应位置 |

完成标准是对外声明有依据、实现与验证能支持该声明。未确认的内容不能扩展成“所有账号可用”“所有云支持”或“全部免费”。
